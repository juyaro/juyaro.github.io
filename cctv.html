모자이크 영역

영상 위를 드래그하면 모자이크가 바로 만들어집니다. 보여야 하는 사람(민원인 본인 등)은 제외 영역으로 지정하세요.

모든 영역은 시작 → 종료 지점 사이에서만 적용됩니다. 기본값은 "만든 시점 → 영상 끝"이며, 카드의 시작·종료 입력이나 타임라인의 주황 막대 손잡이로 조정합니다. 제외 영역은 최상위 레이어로, 그 구간 안에서는 모자이크·자동 감지보다 항상 우선해 원본을 보여줍니다. 영역을 클릭해 선택하고 모서리를 끌어 크기를 조정하며, Ctrl+클릭으로 여러 영역을 묶어 함께 이동할 수 있습니다. 우클릭하면 바로 가기 메뉴가 열리고, 영상 위의 노란 자동 감지 박스를 클릭하면 제외 처리하거나 수동 모자이크로 고정할 수 있습니다.

CCTV 영상 배부 방법
1
민원인 배부용 HTML 파일 PC 저장- PC 재생 민원인: 저장파일 메일 송부로 종료
- 휴대폰 재생 민원인: 2~4번 순서대로 진행
2
VERCEL / Netlify 사이트에서 영상 배포vercel.com/drop 또는 app.netlify.com/drop를 열고, 저장된 HTML 파일을 직접 드래그 앤 드롭합니다.
3
HTTPS 주소 확인무료 HTTPS 호스팅과 자동 배포가 완료되면 URL이 생성됩니다. 해당 웹사이트에서 영상 재생, 암호 입력, 열람기한 작동을 확인합니다.
4
CCTV 요청인에게 URL 송부확인된 URL 주소를 메일로 보내고, 열람 암호는 전화나 문자 등 별도 경로로 전달합니다.
송부 전에는 반드시 본인이 먼저 URL에 접속해 재생 및 보안 확인을 완료하세요.
