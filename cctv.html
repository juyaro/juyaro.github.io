0. AVI → MP4 변환 (선택)

⚠ 이 파일을 내 컴퓨터에서 직접 더블클릭해서(file://) 열어보고 계신 것 같습니다. 변환 엔진은 보안상 이런 방식에서는 인터넷에서 파일을 받아오지 못해 항상 실패합니다.
해결 방법: 이 HTML 파일을 홈페이지(웹서버)에 올려서 https:// 주소로 접속하시거나, PC에서 간단한 로컬 서버로 열어주세요. 그전까지는 다른 프로그램으로 미리 MP4로 변환한 뒤 "1. 영상 불러오기"에서 그 MP4를 선택해 사용하실 수 있습니다.
최초 변환 시 변환 엔진(수십 MB)을 내려받아 다소 시간이 걸릴 수 있습니다. 변환은 이 브라우저 안에서만 처리되며, 변환이 끝나면 자동으로 PC에 MP4로 저장됩니다.

CCTV 영상 배부 방법

1
민원인 배부용 HTML 파일 PC 저장 - PC 재생 민원인: 저장파일 메일 송부로 종료
- 휴대폰 재생 민원인: 2~4번 순서대로 진행
2
VERCEL / Netlify 사이트에서 영상 배포 https://vercel.com/drop 또는 app.netlify.com/drop 사이트를 열고, 저장된 HTML 파일을 직접 드래그 앤 드롭합니다.
3
HTTPS 주소 확인 무료 HTTPS 호스팅과 자동 배포가 완료되면 URL이 생성됩니다. 해당 웹사이트에서 영상 재생, 암호 입력, 열람기한 작동을 확인합니다.
4
CCTV 요청인에게 URL 송부 확인된 URL 주소를 메일로 보내고, 열람 암호는 전화나 문자 등 별도 경로로 전달합니다.
송부 전에는 반드시 본인이 먼저 URL에 접속해 재생 및 보안 확인을 완료하세요.
